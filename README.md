# Firmas

Firma de documentos para abogados en la Argentina: un producto como DocuSign, pensado para
el mercado argentino y para el trabajo de un estudio jurídico.

Es una idea en definición. Se desarrolla con spec driven development sobre
[GitHub Spec Kit](https://github.com/github/spec-kit): primero la especificación, aprobada,
y después el código.
