# Resumen: Plantillas y documentos desde cero

Las plantillas del estudio y la redacción desde cero, dos de las tres formas de empezar un pedido (decisión 11). Detalle en [spec.md](spec.md).

## Requerimientos

| ID | En una línea |
|---|---|
| RF-41 | Hay plantillas del estudio, con nombre, categoría, texto, datos variables y, opcionalmente,… |
| RF-42 | Usar una plantilla pide completar sus datos variables y arma el documento del pedido sin… |
| RF-43 | Las plantillas se listan con su categoría, cuándo y quién la usó por última vez; se filtran… |
| RF-44 | El solicitante crea, edita y borra plantillas |
| RF-44a | El producto trae modelos base, que cualquier estudio usa o copia para hacer su plantilla:… |
| RF-45 | Se puede redactar un documento desde cero en el producto, con formato básico (títulos,… |
| RNF-06 | Usar una plantilla funciona en el celular y en la computadora |

## Lo que más pesa

- Usar una plantilla nunca la cambia.
- El producto trae cinco modelos base; el resto lo crea cada estudio.
